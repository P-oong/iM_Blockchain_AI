> **작성 기준:** 실제 실행 `12m_20260920T092437407643Z_05f961a4`의 저장 결과. 실행일 2026-09-20. 기본 예측기간 12개월. 이 문서는 기획서의 「데이터 구축」「모형 개발」「검증 결과」「활용 및 고도화」에 활용할 수 있도록 작성했다.
>
> **핵심 결과:** 사업자 32,965개에 대한 설명 가능한 평점·등급 파이프라인을 구축했다. 2024년 상반기 위기 진입자 2,821개를 대상으로 한 OOT에서 ROC-AUC 0.5883, KS 0.1287을 기록했고, R1→R5 실제 폐업률은 8.13%→28.67%로 증가했다. 다만 합성 매출을 사용했고 점수 PSI가 0.5478이므로, 현재 성과는 **PoC에서 개발·평가 절차와 위험 순서화를 확인한 것**으로 한정한다.

## 1. 프로젝트 목적과 평가 대상

대구 지역 소상공인 가운데 **행정동·업종의 매출 충격에 노출된 사업자의 향후 영업지속 가능성**을 예측하여 금융·정책지원 검토에 활용할 수 있는 정보를 제공한다. 공공데이터의 인허가·폐업 이력으로 결과를 정의하고, 초기 PoC에서는 합성 매출로 위기 환경을 구성했다.

신용평가에서 사용하는 WOE·로지스틱·스코어카드 방법을 차용하되, 예측 대상은 **대출 연체·채무불이행이 아닌 12개월 내 폐업**이다. 사업자별 실제 매출 회복도 관측하지 않으므로, 생존확률을 매출 회복률로 표현하지 않는다.

| 구분 | 본 프로젝트의 정의 |
|---|---|
| 평가 모집단 | 합성 상권·업종 매출이 위기 기준을 만족했을 때 실제 영업 중이던 사업자 |
| 관측 단위 | 관리번호로 식별되는 사업장별 최초 적격 위기 진입 1건 |
| 원래 종속변수 | `Y_12M=1`: 12개월 영업지속, `Y_12M=0`: 기간 내 폐업 |
| 학습 타깃 | `BAD=1-Y_12M`; 폐업 1, 생존 0 |
| 확률 출력 | `p_bad=P(12개월 내 폐업 ∣ 위기 노출, X)`, `p_survival=1-p_bad` |
| 점수 출력 | 로그오즈 기반 `score`, 별도 0~100 표시값 `recovery_score` |
| 등급 방향 | R1은 가장 낮은 예측 폐업위험, R5는 가장 높은 예측 폐업위험 |
| 활용 구상 | 은행·지자체 담당자의 상담·지원 검토와 모니터링 보조; 실제 사용 정책은 별도 설계 |

현재 구현에는 실제 금융지원 집행, 대출 승인, 서비스 배포 또는 정책 효과 검증이 포함되어 있지 않다.

## 2. 전체 개발 흐름과 기존 모형의 변경 사항

```text
공공 사업장 이력 + 합성 상권 매출
→ 위기 진입 사업자와 미래 영업지속 라벨
→ dmdrlt4.csv 검증·완전 중복 제거
→ 시점·결과 관측기간을 고려한 Train / Validation / OOT 분리
→ Train의 품질 점검·Fine/Coarse WOE·IV
→ Train WOE 상관성 제거
→ Validation에서 L1 로지스틱 C 선택
→ Validation 내부 확률 보정 비교 및 재적합
→ Validation의 실제 폐업률로 등급 경계 확정
→ 계수·구간·보정·등급을 고정한 OOT 평가
→ 전체 입력 사업자의 확률·점수·등급과 단계별 보고서 저장
```

| 기존 노트북의 방식 | 이번 실행에서 구현한 방식 |
|---|---|
| 위험여부를 그대로 사용 | `BAD=1-Y_12M`로 폐업 방향 명시 |
| 전체 데이터 IV·WOE | Train에서만 구간·WOE·IV 적합 |
| 랜덤 분할 | 미래 결과가 다음 평가시점으로 넘어가지 않도록 기간 간격 확보 |
| 기존 지역모형의 수동 구간 | 현재 변수의 Train 분포와 폐업률로 새 구간 생성 |
| KS·t-test p값으로 변수 제거 | IV·구간 품질·상관성·L1·시점 안정성 진단으로 변경 |
| 고정 C 사용 | 7개 C 후보를 Validation에서 비교 |
| 확률 보정 없음 | 양의 기울기 sigmoid 보정 채택 여부 비교 |
| 일정 점수 간격 등급 | Validation 실제 폐업률·표본 수·사건 수를 반영한 등급 |
| AUC·KS 중심 평가 | PR-AUC·AP·Brier·log loss·확률 보정·PSI·군집 불확실성 추가 |
| 셀 실행 순서와 기존 메모리에 의존 | 모듈화한 학습 코드와 결과 조회 노트북으로 구성 |

기존 노트북은 `notebooks/archive/`에 보존했다. 현재 노트북은 기본적으로 저장 결과를 조회하며, `RUN_TRAINING=True`일 때 새 실행을 수행한다.

## 3. 데이터 구축 및 종속변수 정의

### 3.1 상위 데이터 파이프라인

공공 사업장 원본은 `data/raw/IMBANK_raw.csv`이며, 기존 라벨링 파이프라인에서 정제한 139,844개 관리번호를 바탕으로 코호트를 구성했다. 합성 매출은 `행정동 × 업종 × 분기` 단위이며, 2015Q1~2025Q4의 72,028개 시장·분기, 1,637개 시장으로 구성된다. 생성 시드는 42이고, 충격확률 설정은 0.08이다. 이는 **생성기의 충격확률 설정값이며 실제 위기 관측 비율을 뜻하지 않는다.**

합성 매출 생성에는 미래 폐업 결과를 사용하지 않는다. 상위 라벨링 코호트는 77,736개 사업장이지만, 이번 모형의 실제 입력은 추가 변수가 결합된 `dmdrlt4.csv`다. 두 모집단의 규모를 혼용하지 않는다.

### 3.2 위기 노출 기준

시장 m, 업종 k, 분기 t에 대해 다음을 계산한다.

```text
sales_yoy = Sales(m,t) / Sales(m,t-4) - 1
peer_yoy  = 동일 업종 비교시장 매출합(t) / 매출합(t-4) - 1
peer_gap  = sales_yoy - peer_yoy
Crisis    = (sales_yoy <= -0.20) AND (peer_gap <= -0.10)
```

`peer_yoy`는 현재와 전년 동분기에 모두 관측된 동일 업종 시장의 **매출 합계 비율**이며, 개별 시장 성장률의 단순 평균이나 공식 대구 전체 매출 통계가 아니다. 평가 대상 시장도 비교 합계에 포함된다. 기본 연속 조건은 1분기다.

위기 조건은 **라벨을 붙일 대상을 선정하는 조건**이다. 위기 여부 자체를 Y로 학습하지 않는다.

### 3.3 기준일과 생존·폐업 판정

1. 시장의 위기 에피소드 시작 분기를 찾는다. 연속 위기 분기들을 매번 새 샘플로 생성하지 않는다.
2. 분기말 `t0`에 인허가일이 도래했고, 폐업일이 없거나 `폐업일>t0`인 사업장만 연결한다. `폐업일=t0`이면 제외한다.
3. 각 사업자의 최초 적격 에피소드 시작 1건을 선택한다. 진행 중인 위기에 새로 개업한 사업자는 해당 에피소드 시작 샘플에 소급 포함하지 않는다.
4. `horizon_end=t0+12개월`로 설정하며 월말을 보존한다.
5. `(t0, horizon_end]`에 폐업하면 Y=0, 해당 종료일까지 폐업하지 않으면 Y=1이다.
6. 성과기간 전체를 관측할 수 없으면 Y는 NA다. 조기 폐업을 이미 알더라도 미성숙 성과기간은 학습에서 제외하는 기존 기준을 유지한다.

예: `t0=2024-06-30`이면 종료일은 `2025-06-30`이다. 종료일 당일 폐업도 BAD=1에 포함된다.

관측 종료일 `2025-12-31`은 **사용자와 합의한 가정**이며, 실제 폐업 수집 완전성이 확인된 날짜가 아니다. 상위 파이프라인은 12·18·24개월 라벨을 지원하지만, 이번 입력에는 `Y_24M`이 없다. **이번 문서에서 보고하는 학습·검증 결과는 12개월 모델 한 개**이며, 18·24개월 결과를 검증 완료로 표현하지 않는다.

분기 매출을 분기말에 사용할 수 있다고 가정했고, 실제 공표 지연은 반영하지 않았다. 지역·업종의 과거 변경 이력도 완전히 복원하지 않았다.

## 5. 독립변수 정의와 미래 정보 차단

150개 입력 열 가운데 기존 라벨링 메타데이터의 허용목록에 해당하는 **33개 변수**만 후보로 사용했다. 식별자·타깃·지역 식별 등 19개와 시점이 확인되지 않은 추가 정보·메타데이터 98개는 사용하지 않았다. 원래 허용목록 34개에서 `읍면동`을 제외했으며, `구`는 후보에 포함한 후 IV 기준에서 제거됐다.

| 변수군 | 후보 예시 | 정보 시점 |
|---|---|---|
| 사업장 특성 | 업력 일수·연수·개월수, 최근 1·3년 신규 여부 | t0 기준; 인허가일을 개업일 대용으로 사용 |
| 업종·구 | 업종, 구 | 원본 사업장 분류; 동명·행정동코드는 모델에서 제외 |
| 과거 상권 규모 | 구·동 전체 사업장 수, 동일 업종 수·비율 | t0의 직전 분기말 |
| 과거 진입·폐업 환경 | 신규·폐업 수, 신규진입률, 폐업률, 순증감률 | 직전 분기말까지 종료된 과거 4분기 |
| 상대 업력 | 동·업종 평균 업력, 지역 대비 업력 비율 | 직전 분기말 스냅샷 |
| 매출 환경 | 매출액·이용건수, YoY·Peer Gap, QoQ, 추세·변동성·하락기간·순위 | t0까지의 합성 시장 매출 |

최종 선정된 과거 상권 비율은 다음과 같이 정의한다. `s`는 직전 분기말, `b`는 그로부터 4분기 전 분기말이며, `N_b`는 창 시작 영업 사업장 수, `E`는 `(b,s]`의 신규 수, `C`는 같은 창의 폐업 수다.

```text
동_동일업종_신규진입률_4q_lag1q = E / N_b
동_동일업종_폐업률_4q_lag1q   = C / (N_b + E)
동_동일업종_신규수_4q_lag1q   = E
sales_qoq                    = Sales(t) / Sales(t-1) - 1
업력_연수                    = (t0 - 인허가일의 일수) / 365.25
```

분모가 0이면 결측이다. 신규진입률은 1을 넘을 수 있다. 사업장 수는 확보·정제한 공공데이터의 업종 범위에 해당하며 공식 전체 사업체 수와 동일하지 않다. 과거 상권 지표에는 해당 시점에 영업 중이던 평가 대상 사업장도 포함될 수 있다.

관리번호, t0, 기준분기, 위기 플래그, 모든 기간의 Y·BAD, 성과기간 종료일·관측상태, 합성 충격의 내부 정답 변수는 X에 사용하지 않는다. 지하철·서비스인구·주민인구 변수는 기준일·공개일을 확인할 수 없어 기본 모델에서 제외했다. 향후 추가할 때는 변수별 사용가능일 열을 지정하고 모든 행에서 `사용가능일<=t0`를 검사한다.

### 7.2 Train 전용 구간 생성

수치형 변수는 최대 10개 분위수 구간에서 시작한다. 고유값이 적으면 고유값 경계를 사용하며, 동률 값이 서로 다른 구간에 나뉘거나 빈 구간이 생기지 않도록 경계를 관측값에 맞춘다. 일반 구간은 `(하한, 상한]`이다.

범주형인 구·업종은 Train의 표본 수가 적은 범주를 먼저 묶고, Train 폐업률 순서로 정렬해 인접 범주를 병합한다. 업종의 구간 순서는 업종 이름이나 법정 분류의 순서가 아니다.

Coarse 단계에서는 인접 구간을 병합하여 폐업률의 단조성을 만들고, 최소 인원·사건 수와 최대 구간 수를 맞춘다. 수치형은 증가·감소 두 방향을 Train에서 비교하고, IV를 더 보존하는 방향을 채택했다.

| 설정 | 이번 실행값 |
|---|---|
| Fine 수치 구간 최대 수 | 10 |
| Coarse 일반 구간 최대 수 | 5 |
| 일반 구간 최소 표본 | Train의 5%; `ceil(14,164×0.05)=709`개 |
| 구간 최소 폐업 / 생존 | 각 20개 |
| 인접 병합 선택 | 단조성·지지 조건을 만족시키며 IV 보존을 우선 |
| 결측 | 별도 MISSING 구간; 일반 구간 최대 수와 분리 |
| 미관측 범주 | UNSEEN, 중립 WOE=0 |
| Train에 없던 결측 | 중립 WOE=0 |
| 평활화 | 0.5 |

Train에 실제 관측된 MISSING 구간에는 해당 Train 통계로 WOE를 계산한다. 모든 결측에 WOE=0을 적용한 것은 아니다. 일반 구간의 단조성은 결측 구간까지 포함한 일렬의 단조성을 보장하지 않는다.

### 7.3 WOE·IV 계산과 기준

구간 i의 폐업 수를 B_i, 생존 수를 G_i, 전체 폐업·생존 수를 B·G라고 하고, K를 해당 변수에서 표본이 있는 구간 수로 정의한다. 실제 관측된 결측 구간은 K에 포함하고 빈 UNSEEN 구간은 제외한다.

```text
bad_dist_i  = (B_i + 0.5) / (B + 0.5 × K)
good_dist_i = (G_i + 0.5) / (G + 0.5 × K)
WOE_i       = ln(bad_dist_i / good_dist_i)
IV          = Σ (bad_dist_i - good_dist_i) × WOE_i
```

이번 구현은 **BAD/GOOD 방향의 WOE**를 사용한다. WOE가 높을수록 해당 구간의 상대적 폐업 비중이 높다. 라이브러리마다 GOOD/BAD 정의가 다를 수 있으므로 부호를 혼용하지 않는다.

Coarse IV가 0.02 이상이고 WOE에 변동이 있는 변수를 남겼다. IV 0.5 이상은 누수·편중 검토 대상으로 표시하도록 했으나, 이번 실행에서는 해당 변수가 없었다. 최대 IV는 업력 계열의 0.150116이다.

### 7.4 구간 품질의 예외

4개 변수의 별도 결측 구간은 최소 지지 조건을 만족하지 못했다. 신규진입률·순증감률은 각 11개, 과거 폐업률·평균 업력은 각 2개다. 그중 **신규진입률과 과거 폐업률은 최종 모델에 남았다.** 코드가 이 구간을 합치거나 탈락시키지는 않았고, 경고를 통계에 남겼다.

극소 결측 구간은 평활화 0.5의 영향을 크게 받는다. 예를 들어 과거 폐업률의 MISSING은 표본 2개·폐업 0개인데도 WOE가 양수가 된다. 이를 “결측이면 폐업위험이 높다”는 실증 결론으로 해석하지 않고, 병합·중립 처리·별도 표시 정책을 재검토할 대상으로 둔다.

원 로지스틱 선형식은 다음과 같다. `WOE_j(X_j)`는 Train에서 고정한 해당 변수 구간의 값이다.

```text
z = -2.213107413832 + Σ β_j × WOE_j(X_j)
p_bad_raw = 1 / (1 + exp(-z))
```

표의 exp(β)는 **WOE가 1 증가할 때의 조건부 오즈비**다. 업력 1년 증가의 오즈비로 해석해서는 안 된다. 최종 계수 7개는 모두 양수지만, 원변수 방향은 구간별 WOE로 결정된다.

업력은 Train에서 오래될수록 낮은 폐업률을 보였다. 반면 합성 매출의 `sales_qoq`는 값이 커질수록 Train 폐업률이 증가하는 방향으로 선택됐다. 이를 “매출 증가가 폐업을 유발한다”는 인과관계로 주장하지 않는다. 위기 조건으로 제한된 표본, 합성 매출 구조, 업종·상권 구성에 대한 업무적 검토가 필요하다.

## 10. 폐업확률 보정

양의 기울기를 가진 sigmoid 보정을 비교했다. Validation의 2022Q1~Q2에서 보정계수를 시험 적합하고, 2022Q3~Q4 2,883개 사업장·폐업 362개에서 미보정과 비교했다. Brier와 log loss가 모두 감소할 때만 보정을 채택하도록 했다.

| 방식 | 점검 표본 | AUC | Brier | Log loss | 채택 |
| --- | --- | --- | --- | --- | --- |
| none | 2,883 | 0.597206 | 0.108369376 | 0.371364249 | 아니오 |
| sigmoid | 2,883 | 0.597206 | 0.108105507 | 0.370401097 | 예 |

두 확률 오차가 모두 개선되어 sigmoid를 채택한 다음 **Validation 전체 5,558개로 보정계수를 재적합**했다. 저장된 최종식은 다음과 같다.

```text
z_cal = 0.473559509800 + 1.171042692403 × z
p_bad = 1 / (1 + exp(-z_cal))
p_survival = 1 - p_bad
```

양의 기울기 조건을 사용하여 위험 순서와 점수 방향을 유지했다. 보정계수 최적화에는 log loss와 L-BFGS-B를 사용했고, 절편 범위는 [-20,20], 기울기는 [0.01,10]으로 제한했다. Isotonic 보정이나 다른 보정기의 비교 실험을 수행한 것은 아니다.

이 H1/H2 비교는 **개발용 부분기간 비교**다. C는 이미 Validation 전체 라벨을 사용해 선택했고, 12개월 타깃 특성상 H1의 모든 결과를 H2 시작에 알 수 있는 것도 아니다. 따라서 내부 비교를 독립된 실시간 forward 검증으로 표현하지 않는다. Validation의 모든 결과가 확정된 후, 2024년 OOT 전에 모델·보정·등급을 고정하는 전체 분리를 기준으로 평가했다.

Validation의 최종 확률 보정 지표와 등급 단조성도 같은 Validation으로 적합한 개발 통계다. 실질적인 최종 확인은 OOT에 근거한다. OOT 전체의 평균 예측 폐업률은 **12.9533%**, 실제 폐업률은 **14.0376%**로 **1.0843%p 과소 예측**했다. 보정이 이후 시점에서도 완전히 유지됐다고 주장할 수 없다.

## 11. 평점과 사업자별 설명값 산출

스코어카드 평점과 0~100 표시값을 구분해 제공한다.

```text
factor = PDO / ln(2) = 50 / ln(2)
Score = 600 + factor × [ln((1-p_bad)/p_bad) - ln(20)]
Recovery Score = 100 × (1-p_bad)
```

| 기준 | 의미 |
|---|---|
| 기준점수 600 | 생존:폐업 odds가 20:1인 확률에 대응; p_bad=1/21 |
| PDO 50 | 생존:폐업 odds가 2배 좋아지면 평점 +50 |
| Score 방향 | 폐업확률이 높을수록 낮은 점수 |
| Recovery Score | 0~100 범위의 영업지속 확률 표시값 |
| 점수 범위 | 로그오즈 Score는 이론적으로 0~100이나 0~1,000에 제한되지 않음 |

확률 보정이 선형 logit 형태이므로 변수별 배점도 정확하게 합산된다.

```text
basepoints = 536.691041708195
points_j   = -factor × 1.171042692403 × β_j × WOE_j(X_j)
Score      = basepoints + Σ points_j
```

32,965개 출력 전체의 Score는 **465.92~605.50점**, 평균 **537.09점**이었다. Recovery Score는 **75.71~95.57점**, 예측 폐업확률은 **4.43%~24.29%**였다. 이는 입력 표본의 실제 출력 범위이며 운영상의 강제 범위가 아니다.

사업자별 결과에는 관리번호·기준일·집합·실제 Y/BAD, 미보정/최종 폐업확률, 생존확률, 두 점수, 등급을 저장했다. 배점 파일에는 각 선택 변수의 점수와 기본점수를 저장했다. 모든 행에서 변수별 점수 합이 총점과 일치하고, 저장한 JSON 모델을 다시 읽었을 때 점수·등급이 재현되는지 확인했다.

## 13. 모형 성능과 불확실성 검증

### 13.1 평가 지표

| 지표 | 의미 및 해석 방향 |
|---|---|
| ROC-AUC | 폐업자를 생존자보다 더 높은 위험으로 정렬하는 정도; 높을수록 좋음 |

## 14. 변수·점수의 시간 안정성과 설명력

### 14.1 PSI

변수 PSI는 Train에서 고정한 구간으로 계산했다. 전체 평점은 Train 점수의 10분위 경계를 고정했다. 비교 집합에서만 관측된 구간도 포함하고, 각 구간의 두 집합 인원에 0.5를 더해 비율을 계산했다.

```text
PSI = Σ (비교집합 구간비율 - Train 구간비율)
        × ln(비교집합 구간비율 / Train 구간비율)
```

0.25 이상은 검토 대상으로 표시하는 설정이며, 보편적 합격·불합격 기준으로 단정하지 않는다.

| --- | --- | --- | --- |
| 업력_연수 | 0.080147 | 0.593080 | 0.25 이상 |
| 업종 | 0.005784 | 0.021797 |  |
| 동_동일업종_폐업률_4q_lag1q | 0.083163 | 0.200843 |  |
| 동_동일업종_신규진입률_4q_lag1q | 0.078855 | 0.128697 |  |
| 구_동일업종수_lag1q | 0.225577 | 0.602049 | 0.25 이상 |
| sales_qoq | 0.073563 | 0.274014 | 0.25 이상 |

총점 PSI 0.5478, 업력 연수 0.5931, 구 동일업종 수 0.6020, sales_qoq 0.2740으로 분포 변화가 확인됐다. 업력·상권 규모와 점수 구성의 변화가 성능 저하에 어떤 영향을 주었는지는 추가 분석 대상이다. PSI만으로 저하의 원인을 확정하지 않는다.

### 14.3 개별 사업자와 상권 정보의 점수 차이

| 집합 | 에피소드 내 분산 비중 | 에피소드 간 분산 비중 | 개별 특성 배분 비중 | 상권·업종 특성 배분 비중 |
| --- | --- | --- | --- | --- |
| Train | 42.83% | 57.17% | 74.34% | 25.66% |
| Validation | 33.45% | 66.55% | 72.16% | 27.84% |
| OOT | 26.85% | 73.15% | 57.87% | 42.13% |

서로 다른 두 분해 방법이다. 에피소드 내·간 분해는 동일 위기 환경 안에서도 점수가 다른지 확인한다. 개별·상권 분해는 가산 점수의 두 그룹 분산과 공분산을 계산하고, 분산 교차항 `2×Cov`를 두 그룹에 절반씩, 즉 각 그룹에 `Cov`만큼 배분한다. `총분산=개별분산+상권분산+2×Cov`이며, 개별 배분 비중은 `(개별분산+Cov)/총분산`이다. 배분 비중은 음수가 될 수도 있고 **인과적 중요도 비율이 아니다.**

이번 최종 모델에서 개별 사업장 특성으로 남은 변수는 업력 연수다. 나머지는 업종·상권 특성에 포함된다. OOT 점수 분산의 에피소드 내 비중은 26.85%이고, 개별 특성에 공분산을 배분한 비중은 57.87%다. 두 수치가 다른 이유는 개별 업력도 시장 사이에서 분포가 달라질 수 있기 때문이다.
